# Changelog

## 0.1.0 — 2026-11-12

Initial release.

- 22 reference tasks across physics, chemistry, biology, statistics,
  mathematics and economics.
- `level_1` (8 tasks), `level_2` (7 tasks), `level_3` (7 tasks).
- Stable `problem_id`, `task_key`, `task_version` and `reference_hash` for
  every task.
- Same Hugging Face layout as `ai-nikolai/KernelBench`: one `default` config
  with `level_1`, `level_2`, `level_3` splits under `data/`.
- Compatible with `robust-kernelbench >= 0.2.0`.
